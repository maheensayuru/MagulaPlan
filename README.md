# 💍 MagulaPlan

> **A Centralized Digital Wedding Planning Platform for the Sri Lankan Market**

Magula.lk acts as a centralized digital marketplace designed to solve the massive time investment and manual effort required to plan a wedding locally. It eliminates the need for couples to manually track down vendor pricing, availability, and contact details across multiple disconnected social media apps.

## ✨ Core Features

*   **Vendor Directory:** Search, browse, and filter wedding vendors across at least six categories by location and price range.
*   **Budget Tracker:** Create a customized wedding budget, record LKR expenses, and monitor remaining balances with automated alerts.
*   **Guest List & RSVP Manager:** Centralized dashboard to manage guest information, send invitations, and track live RSVP responses.
*   **WhatsApp Integration:** Generate digital invitation links and share them directly with guests through WhatsApp.

## 💻 Tech Stack

### Frontend
*   **Framework:** React
*   **Styling:** Tailwind CSS
*   **Deployment:** Vercel

### Backend
*   **Framework:** Java & Spring Boot
*   **Security:** Spring Security & JWT Authentication
*   **Integrations:** WhatsApp Business API routing
*   **Deployment:** Render

### Database
*   **Database:** MySQL
